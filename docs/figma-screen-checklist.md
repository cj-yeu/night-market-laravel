- [ ] Desktop layout for every main screen

## Primary Prototype Flows

### Client Flow

Register/Login → Discover Markets → Market Details → View Stalls/Foods → Submit Review or Create Visit Plan → Profile

### Admin Flow

Login → Dashboard → Manage Markets → Manage Stalls/Foods → Approve Reviews → Manage Social Media Data
